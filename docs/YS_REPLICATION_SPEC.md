## 3. 与心之塔 / 香蕉塔的差异

1. YS 的 swipe `begin/end` 全是**字符串锚点**（80 个）；两塔全是裸坐标（锚点引用 0）
2. 显式 `"recognition":"DirectHit"` 67 处；两塔 0 处
3. 「原豌 / 芦荟 / 桑葚 / 毒藤」四个词只在 YS
4. `9-1 / 9-2` 只有 YS 引用（抛花到第 9 列）
5. 捡花 `repeat50 / dur5` 只有 YS + FrameWj
6. **大哥滑动4/5**：同 `ROI[172,375,10,67]` 同色带 `250,140,0~255,167,18`，两次判定分叉到 `1-2 / 1-1`，未命中跳 `点波2`
7. `豆槽 → 5-3` 自循环喂豆只有 YS（`豆槽` 作 begin 只在 YS 与 FrameWjCustom_2）
8. `end:[]` 写法 FrameWj 抛花1-4 也有，但 YS 的卡7/卡8 链无人引用

## 5. 必须 1:1（不能简化）

- 大哥滑动 `dur 500` vs 原豌滑动 `dur 100`（两个速度不同，是设计）
- 抛花1 `post_delay 100`
- 捡花 `repeat50 / dur5`
- 全部 `timeout -1`
- `rate_limit` 1000（主线结算）/ 500（boss 结算）
- 喂豆 `post_delay 3000` + 自循环
- 模板 `threshold 0.75`
- ColorMatch `method 4`
- 点波 `repeat 2`
- 确定4 `repeat 3`
